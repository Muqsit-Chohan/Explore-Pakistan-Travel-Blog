# Explore Pakistan — Constitution

## Mission
To inspire travelers to discover Pakistan through rich content and AI assistance.

## Core Principles
1. User First — Easy navigation, fast loading, mobile-friendly
2. Authenticity — Real destinations, honest descriptions
3. Performance — Optimized images, minimal JS
4. Accessibility — Readable fonts, proper contrast
5. Clean Code — TypeScript, reusable components

## Technical Standards
- Next.js 14+ with App Router
- TypeScript for all files
- Tailwind CSS only for styling
- Component-based architecture

## Design Guidelines
- Mobile-first responsive design
- Color: Emerald green on dark gray
- Consistent padding p-4 (mobile) → p-8 (desktop)
