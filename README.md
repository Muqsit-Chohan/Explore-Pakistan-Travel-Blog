# Explore Pakistan — AI Travel Blog

An AI-powered travel website showcasing beautiful destinations across Pakistan.  
Built with modern web technologies including Next.js, TypeScript, Tailwind CSS, and Gemini API.

---

## Features

- Responsive modern UI
- Dark-themed mobile-first design
- AI Travel Chatbot using Gemini API
- Destination listing and detail pages
- Contact and About pages
- Fast performance with Next.js 14

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/explore-pakistan.git
```

Go to project folder:

```bash
cd explore-pakistan
```

Install dependencies:

```bash
npm install
```

Create environment file:

```bash
.env.local
```

Add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

Run development server:

```bash
npm run dev
```

Open in browser:

```bash
http://localhost:3000
```

## Deployment

### Deploy on Vercel

1. Push project to GitHub
2. Open Vercel
3. Import GitHub repository
4. Add environment variable:

```env
GEMINI_API_KEY
```

5. Deploy project
